# Проверка исходного PDF

## Обновление после независимой проверки

Подтверждено проверкой расположения текстовых блоков PDF: все 11 номеров ниже
действительно отсутствуют в исходнике. Следы в повреждённом слое не являются
восстановимыми карточками. По согласованному решению приложение собрано из 190
реальных карточек с исходными номерами. `extract_cards.py` проверяет их структуру
и исключает чужие фрагменты после карточек 55, 108, 120 и 186 по границам страниц.
Поиск недостающих карточек прекращён. Ниже сохранён исторический отчёт первого
запуска; его решение об остановке сборки больше не действует.

## Исторический отчёт

Сборка приложения остановлена на обязательной проверке данных: исходный файл
не содержит 201 чистую пронумерованную запись.

Проверено:

- PyMuPDF: обычное извлечение, сортировка по координатам, бесконечная область
  извлечения, текстовые блоки и `get_texttrace()`.
- Дополнительная проверка через pdfplumber и его последовательность символов.
- Визуальная проверка страниц 24 и 25: после вопроса 55 следует вопрос 58.

Результат:

- Чистых пронумерованных записей: **190**.
- Отсутствуют в чистом тексте: **56, 57, 109, 110, 111, 121, 122, 123, 187, 188, 189**.
- Вопросов **56 и 57** нет даже в полном наборе текстовых объектов PDF.
- Остальные девять номеров обнаружены только в повреждённом слое наложенных
  текстовых объектов. Он не используется как источник карточек.
- Заголовок «201 Karteikarten» не соответствует числу доступных чистых записей.

Для продолжения нужен исправленный полный PDF или исходный документ с
недостающими 11 записями: вопрос, четыре варианта, правильный ответ и объяснение.
Карточки не выдумывались и не перенумеровывались. Приложение и публичный
репозиторий пока не создавались.

Повторить проверку (Python 3 и PyMuPDF):

```powershell
python -m pip install PyMuPDF
python audit_pdf.py --report extraction-audit.json
```

Код завершения 1 означает, что обязательная проверка не пройдена. Скрипт
не создаёт и не перезаписывает `data/cards.json`. Хеш исходного PDF и
машиночитаемые результаты находятся в `extraction-audit.json`.
